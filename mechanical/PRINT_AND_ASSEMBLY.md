# Bionic hand v3 — mechanical model

Place the supplied `Bionic-hand-v3.stl` file in this directory if it is part of the intended release. Inspect the model in a slicer/CAD viewer before printing; STL files may not preserve units.

Document:
- verified overall dimensions and scale
- printer, material, nozzle and layer height
- orientation, supports and infill
- fastener sizes, tendon routing and return mechanism
- actuator mounting and mechanical travel limits
- assembly photos and fit-check results

The STL filename alone does not establish the full assembly or compatible actuator.
